## 摘要
现代人工智能前所未有的计算规模依赖于复杂的、包含数十亿晶体管的片上系统，然而用于验证这些芯片的工作流却仍顽固地停留在人工阶段。尽管大语言模型（LLM）已迅速进入电子设计自动化（EDA）领域，但现有研究中约 74.6% 针对的是静态寄存器传输级（RTL）代码生成，而仿真后验证与交互式波形调试在很大程度上仍未被触及。我们提出 Back-to-the-Future（BTTF），一个端到端的智能体框架，以弥合这一基础设施鸿沟。BTTF 将海量、非结构化的仿真转储数据提炼为规范化的关系型 SQLite 数据库，并将其与一个协作式多智能体编排引擎相结合；该引擎可将自然语言验证查询转换为模式感知的 SQL，同时将信号异常与版本化的 RTL 代码库相关联。在包含 150 条查询的基准测试中，BTTF 达到了 95.33% 的执行准确率，为自主 EDA 验证勾勒出一条切实可行的路径。

## Abstract
The unprecedented computational scale of modern artificial intelligence depends on complex, multi-billion-transistor Systems-on-Chip, yet the workflows that verify these chips remain stubbornly manual. Although Large Language Models (LLMs) have made rapid inroads into Electronic Design Automation (EDA), approximately 74.6% of existing studies target static Register-Transfer Level (RTL) code generation, leaving post-simulation verification and interactive waveform debugging largely untouched. We introduce Back-to-the-Future (BTTF), an end-to-end agentic framework that closes this infrastructural gap. BTTF distills massive, unstructured simulation dumps into a normalized relational SQLite database and couples it with a collaborative multi-agent orchestration engine that translates natural-language verification queries into schema-aware SQL while correlating signal anomalies with versioned RTL repositories. Across a 150-query benchmark, BTTF attains 95.33% execution accuracy, charting a practical path toward autonomous EDA verification.

## 1. 核心问题与研究动机

- **背景**：现代 AI 的计算规模依赖于数十亿晶体管的复杂 SoC，而芯片验证工作流仍高度依赖人工。验证环节已占据超过 70% 的开发周期，成为现代芯片设计的主要瓶颈；遗漏到全芯片回归或流片后测试的功能缺陷会带来指数级的时间与金钱代价。
- **领域失衡**：尽管 LLM 已快速进入 EDA 领域，但约 **74.6%** 的 LLM-for-hardware 研究集中在静态 RTL 代码生成与综合，仿真后波形调试与动态验证几乎未被触及。
- **核心障碍（"Infrastructural Impedance"，基础设施阻抗）**：当动态仿真失败时，工程师需在图形化波形查看器中手动翻阅 TB 级时序转储数据。原始 ASCII 波形转储（如 VCD）存在三大问题：
  - 体积远超模型上下文窗口数个数量级；
  - 缺乏结构化语义索引；
  - 不提供智能体可调用的原生低延迟查询接口。
- **核心主张**：制约智能体波形调试的瓶颈是**数据基础设施，而非模型能力**。论文认为应"回到"经典 EDA/数据库范式，将不透明波形规范化为可查询存储，再让专用智能体在其上操作。

## 2. 方法论：BTTF 框架

BTTF 由两个通过"单一关系契约"耦合的子系统构成。

### 2.1 离线波形预处理流水线

- **输入**：仿真器输出的专有二进制波形（`.fsdb`）或 ASCII 值变转储（`.vcd`），SoC 级模块的原始 VCD 常超过 10 GB。
- **输出**：规范化关系型 SQLite 数据库（`waves.db`），围绕两张主表构建：
  - `signal_metadata`：记录静态信号声明（RTL 信号名、变量类型等），带 `id`；
  - `signal_changes`：以 `(time, value)` 时间戳转储记录时序行为，外键关联元数据。
- **设计思想**：将"信号是谁"与"信号做了什么"分离，使智能体可独立推理结构与时间，仅在查询需要时做连接。
- **覆盖感知的在线剪枝策略**（避免把可扩展性问题从文件系统搬到数据库）：
  - **时钟剪枝**：高频时钟翻转占主导但调试信息量低；由于每行均有时间戳，跳过时钟转换不会丢失时间锚点。
  - **在线非活跃信号剪枝**：维护 `vcd_id_to_db_id` 哈希映射与每信号翻转计数器 `signal_change_count`，支持两级策略——丢弃静态零翻转连线（ZERO），或进一步丢弃翻转率低于设计平均值的网络（AVG）。
  - **批量插入**：将转换分组批量写入，消除逐行插入的 SQLite 事务开销。

### 2.2 LLM 驱动的多智能体编排引擎

- **编排智能体（Orchestration Agent）**：将自然语言查询分解为子目标，路由至专用智能体，并审计合并后的答案。
- **分析智能体（Analysis Agent）**：配备模式感知的多查询执行工具，在两表上组合 SQLite 查询，处理作用域发现、事件检查、翻转计数；对功耗热点检测等复杂任务采用迭代式函数调用循环，执行多轮查询并聚合多周期信号统计。
- **验证智能体（Verification Agent）**：通过正则表达式赋值评估 SVA 规则（`ASSERT`、`ASSERT_STATIC`、`ASSERT_NEVER`、`ASSERT_KNOWN`、`COVER`），将波形异常关联回版本控制源码。
- **评估智能体（Evaluation Agent）**：在返回根因分析前，按五条标准审计候选查询——(1) 正确性（过滤/聚合/连接与用户意图的保真度）；(2) 完整性（所需列与时间条件的覆盖）；(3) 效率（索引使用与避免冗余连接）；(4) 模式遵循（严格符合两表模式）；(5) 上下文理解（正确推断隐含仿真时间尺度与层次作用域）。
- **协作机制**：智能体仅通过跨轮次维护的动态会话上下文通信；配合失败查询的自纠正循环，各智能体保持窄领域专精而不失全局一致性。
- **根因诊断**：当断言规则在自纠正后仍被违反，智能体自动隔离精确违规时间戳，并反向追溯断言表达式中所有前件操作数在 `t ≤ t_violation` 的先前值，定位问题子信号（例如"断言在 t = 6929 ns 失败，因 clk 为高时 req_sel 跳变为未知态 x"）。

## 6. 主要结论与发现

- **总体性能**：BTTF 在 150 条查询基准上达到 **95.33% 的执行准确率**，在调试原语上近乎完美，在更难的分析与验证任务上表现稳定可靠。
- **架构收益**：多智能体协作架构在五标准质量审计上比单体单智能体基线**高出 17.3%**；单体智能体虽响应更快，但常出现上下文混乱、模式幻觉与多跳验证任务上的因果追踪退化，仅得 3.35/5.00 分。
- **延迟权衡**：专用化委托带来平均 **1.96×** 的延迟开销，论文认为这是生产级 EDA 工作流中保证鲁棒、无幻觉验证的"实际且必要的权衡"。
- **预处理结论**：关系模式优化不是实现细节，而是响应式智能体交互的先决条件。时钟移除即可缩减 66.20% 足迹、降低 3.28× 延迟，同时保留 98.51% 功能翻转覆盖；零翻转剪枝达到 72.18% 缩减并保留活跃网络 100% 覆盖；低于均值剪枝压缩最狠（86.97%）但牺牲 35.77% 覆盖率，标记了安全压缩的边界。
- **核心论断**：通过将 TB 级波形重构为紧凑、厂商无关的关系模式，BTTF 把棘手的上下文问题转化为现代 LLM 已擅长的常规 text-to-SQL 问题——**自主 EDA 验证将经由智能体与设计数据之间更好的接口来实现，而非仅靠更大的模型**。
