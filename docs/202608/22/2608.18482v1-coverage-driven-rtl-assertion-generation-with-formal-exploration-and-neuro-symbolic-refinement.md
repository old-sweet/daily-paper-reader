## 摘要
硬件功能验证依赖于高质量的断言来暴露设计错误并建立对寄存器传输级（RTL）设计的信心。然而，现有的断言挖掘方法仍然难以生成完整且可靠的断言集：随机或有限的轨迹无法覆盖难以到达的行为，一次性生成几乎无法提供关于哪些未被验证或应如何改进断言集的反馈。因此，即使生成了大量断言，关键设计行为仍可能未被覆盖。我们提出了NeuroAssertion，一个覆盖驱动的断言生成框架，它在一个统一框架内结合了形式化轨迹生成、语法引导综合（SyGuS）和智能体启发的细化过程。我们的框架首先将难以到达的控制流条件转换为形式化可达性目标，使用模型检查生成行为多样化的轨迹，并通过SyGuS从这些轨迹中挖掘初始断言。随后，它在验证反馈下进行有针对性的智能体启发式细化：一个LLM首先为未覆盖区域提出候选断言，若候选断言未通过形式化检查，第二个LLM生成修复语法，以指导神经符号修复过程中的约束符号综合。实验结果表明，该框架生成的断言数量约为传统断言挖掘方法的2倍，变异覆盖率约为其2倍。

## Abstract
Hardware functional verification relies on high-quality assertions to expose design bugs and establish confidence in Register Transfer Level (RTL) designs. Yet existing assertion mining methods still struggle to produce complete and reliable assertion sets: random or limited traces fail to cover hard-to-reach behaviors, and one-shot generation provides little feedback about what remains unverified or how the assertion set should be improved. As a result, critical design behaviors can remain uncovered even when many assertions are generated. We present NeuroAssertion, a coverage-driven assertion generation framework that combines formal trace generation, syntax-guided synthesis (SyGuS), and an agent-inspired refinement process within a unified framework. Our framework first converts hard-to-reach control-flow conditions into formal reachability objectives, uses model checking to generate behaviorally diverse traces, and mines initial assertions from these traces with SyGuS. It then performs targeted agent-inspired refinement under verification feedback: one LLM first proposes candidate assertions for uncovered regions, and if a candidate fails formal checking, a second LLM generates a repair grammar that guides constrained symbolic synthesis in a neuro-symbolic repair procedure. Experimental results show that this framework delivers around 2X more assertions and about 2X higher mutation coverage than traditional assertion mining methods.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架（NeuroAssertion）

由两个阶段组成：

- **S1：形式化探索驱动的初始断言挖掘**
  - 核心思想：用形式化可达性分析主动寻找随机仿真难以触达的执行路径，为下游SyGuS挖掘提供更丰富的轨迹基础。
  - 实现细节：
    - 对RTL进行**插桩（Instrumentation）**：为每个分支条件引入零初始化的辅助覆盖寄存器 `br_cov`，并在分支命中时置位对应比特位。
    - 将覆盖比特位上的断言（如 `br_cov[b0] == 1'b0`）作为**形式化可达性目标**，用模型检查器求解反例轨迹，获得可执行目标分支的测试向量。
    - 在获得的扩充轨迹上，用 SyGuS 在 CEGAR 循环中合成初始断言集 A₀。
- **S2：覆盖驱动的神经符号细化**
  - 核心思想：以突变覆盖率为反馈，将未覆盖的突变点转化为"未覆盖义务（Uncovered Obligations）"，驱动两阶段细化循环。
  - 两个子阶段：
    1. **义务驱动的神经提议（Obligation-Driven Neural Proposal）**：第一个 LLM（LLM₁）根据未覆盖义务和RTL上下文，通过结构化提示逐步推理，生成候选断言集合 Ã。提示工程包含四个步骤：突变定位与上下文提取 → 电路类型检测 → 行为意图推断 → 信号提取与断言合成。输出为结构化 JSON，保证下游形式化检查可直接处理。
    2. **文法约束的符号修复（Grammar-Constrained Symbolic Repair）**：候选断言经形式化验证，若失败，由第二个 LLM（LLM₂）生成面向失败信号集合 S 的**修复文法** G = LLM₂(R, S)；然后在此文法约束下运行 SyGuS 求解修复断言 a★ = SyGuS(G, C)。若仍失败，则保存新反例并切换到默认文法，继续反例引导的符号综合。

### 2.2 算法流程（Algorithm 1）

对每个未覆盖义务 u：
1. LLM₁ 生成候选断言 ã；
2. 形式化检查：
   - 通过 → 直接加入断言集；
   - 失败 → 提取信号集 S，LLM₂ 生成修复文法，运行文法引导修复；
3. 修复成功 → 加入断言集；修复失败 → 更新约束集、切换到默认文法重试。

## 6. 主要结论与发现

1. **断言数量显著提升**：相比SMART，NeuroAssertion在大多数基准上生成约 **2倍** 数量的断言（如I2C：89→244，Ibex_controller：136→297，Pico：358→477）。
2. **突变覆盖率翻倍**：整体突变覆盖率约为SMART的2倍；部分基准提升尤为显著（I2C：10.51%→36.21%，Ibex_decoder：6.45%→32.31%，Pico：14.63%→37.80%）。
3. **两大组件均不可或缺**：消融实验表明，仅去除反馈细化即可导致覆盖率大幅下降（如I2C从36.20%降到16.96%），再去除形式化探索则进一步恶化（降至10.40%）。
4. **直接LLM生成远不够**：GPT-5 w. planning即使有提示级规划，在复杂基准上生成断言数量极少（如Multdiv为0条），覆盖率远低于NeuroAssertion（如Pico：1.74% vs 37.80%），证明单纯依赖LLM推理不足以做高质量验证。

## 7. 优点

- **以覆盖率为导向的闭环设计**：将突变覆盖率从"事后评估指标"提升为"显式细化信号"，使断言集构建具有方向性。
- **形式化探索+神经提议+符号修复的优势互补**：LLM负责语义理解与候选搜索空间扩展，形式化工具负责严格验证与反例提供，SyGuS在约束文法下完成可靠修复——各组件各司其职。
- **结构化提示设计**：四步推理流程（定位→检测→推断→合成）可复现性强，输出结构化JSON便于自动化下游处理。
- **修复Grammar的思路新颖**：用LLM生成修复文法而非直接修复断言，避免"重新生成"带来的语义信息丢失，同时约束了符号搜索空间。
- **评估指标严格**：使用形式化验证而非仿真来判断断言有效性，用突变覆盖率衡量断言质量，具有较强的实践参考价值。
- 方法可推广性强：核心思想不依赖特定LLM或特定求解器。
