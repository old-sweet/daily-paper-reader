## 摘要
大语言模型(LLM)越来越多地被用于从自然语言规范生成寄存器传输级(RTL)设计。然而，在早期阶段评估功能正确性仍是一项根本性挑战。现有的无Oracle方法要么依赖于基于仿真的协议，这依赖于可能失败或在不同模型间变化的LLM生成的测试平台，要么依赖于LLM作为评判者的启发式方法，这会产生不一致的预测。我们提出了NoTB，一个无Oracle的分诊框架，它从跨模型形式化共识中推断正确性。NoTB从多个独立训练的LLM家族生成RTL实现，并应用顺序等价性检查(SEC)来识别可证明等价的设计。我们表明，SEC等价簇内模型家族的多样性会产生校准的正确性信号，从而在不需测试平台的情况下实现风险覆盖率权衡。在78个CVDP RTL生成任务中，四家族形式化共识在27%覆盖率下达到94.7%的精确度；三家族共识在33%覆盖率下达到87%的精确度。这些操作点使设计者在获得可信测试平台或黄金RTL之前，能够进行可调的接受/延迟规则。总体而言，NoTB证明了形式化跨模型协议为高置信度分诊提供了可靠基础，而无需依赖模型的Oracle。

## Abstract
Large language models (LLMs) are increasingly used to generate register-transfer-level (RTL) designs from natural-language specifications. However, assessing functional correctness at early stages remains a fundamental challenge. Existing oracle-free approaches rely either on simulation-based agreement, which depends on LLM-generated testbenches that can fail or vary across models, or on LLM-as-a-judge heuristics, which produce inconsistent predictions. We introduce NoTB, an oracle-free triage framework that infers correctness from cross-model formal consensus. NoTB generates RTL implementations from multiple independently trained LLM families and applies Sequential Equivalence Checking (SEC) to identify designs that are provably equivalent. We show that the diversity of model families within an SEC-equivalent cluster induces a calibrated correctness signal, enabling risk-coverage tradeoffs without requiring testbenches. On 78 CVDP RTL-generation tasks, four-family formal consensus achieves 94.7% precision at 27% coverage; three-family consensus achieves 87% precision at 33% coverage. These operating points give designers a tunable accept/defer rule before a trusted testbench or golden RTL is available. Overall, NoTB demonstrates that formal cross-model agreement provides a reliable basis for high-confidence triage without model-dependent oracles

- 大语言模型（LLM）已能直接从自然语言规格说明生成可综合的寄存器传输级（RTL）硬件设计，但早期阶段评估这些设计的**功能正确性**是根本性挑战。

- 现有无Oracle方法存在根本局限：
  - **LLM-as-a-judge**：用辅助模型预测正确性，缺乏形式化保证，且有强烈模型依赖偏差——不同生成模型间的虚假接受率可相差高达45%。

- NoTB的核心含义：用**形式化保证的共识**（SEC证明的跨模型等价性）替代**启发式共识**（仿真/学习信号），为无Oracle场景提供可靠、可校准、可调阈值的高置信分诊信号。

## 2. 论文提出的方法论

**核心思想：**

> 如果多个独立训练的LLM家族生成的RTL实现，经顺序等价性检查（SEC）证明在整个输入空间上行为等价，那么这种共识是**设计本身的性质**而非测试台的性质，因此更可能反映正确性。

**技术流程（四阶段）：**

1. **多模型RTL生成**
   - 设模型家族集合 M = {m₁, ..., m_M}，每个家族采样K个实现，得到候选集 D(s)。
   - 统一提示约束：单一顶层模块、无SystemVerilog专属结构、无仿真专用结构（initial块、延迟）、单驱动纪律，保证下游SEC兼容性。

2. **形式等价聚类**
   - 用Cadence JasperGold对候选实现做**两两SEC比对**，从端口名推断时钟/复位信号。
   - SEC结果为三类：equivalent / non-equivalent / inconclusive；仅当等价被证明时才添加图边。
   - 构建无向图 G(s) = (V, E)，其连通分量定义等价簇 C(s)；边的添加保持忠实于个别SEC证明，簇则通过传递闭包形成。

3. **增量式SEC剪枝**
   - 解决朴素全对比 O(|D|²) 开销过高：哈希去重合并完全相同文件；利用并查集维护等价分量，同簇内跳过重复比较；记录已证非等价关系，避免冗余跨簇比较。
   - 这些优化只影响哪些比较被跳过，不影响哪些等价被信任——簇仍仅由被SEC证明的等价关系连接而成。

4. **置信度 = 模型多样性**
   - 对每个簇C定义模型计数：model_count(C) = |{model(d) : d ∈ C}|，即簇内覆盖的不同LLM家族数。
   - 取最大簇 C* 的模型计数作为该规格的置信度；若大小并列，取模型计数更高者。
   - 设定阈值τ，置信度 ≥ τ 则接受该规格，否则延迟到现有验证流程。
   - 该方法本质上是**选择性预测**方法，而非通用正确性分类器。

## 6. 论文的主要结论与发现

1. **仿真一致性聚类是测试台依赖的**：在相同候选池上，mc≥4精度随测试台生成模型在43%~84%间大幅波动，而formal SEC稳定达到94.7%。
2. **模型计数是校准的正确性信号**：精度随模型计数单调上升——mc≥1为63%，mc≥2为85%，mc≥3为87%，mc≥4达94.7%，高共识与低共识组差异统计显著。
3. **NoTB提供可用操作点**：四家族共识——94.7%精度/27%覆盖率；三家族共识——87%精度/33%覆盖率；设计者可据此选择匹配验证预算的阈值。
4. **信号对单模型不敏感**：留一消融中所有设置仍保持高精度（90%~100% at mc≥3），证明方法可移植且不绑定任何特定模型。
5. **采样收益递减**：K≥3后覆盖增长趋缓，说明每家族少量样本即可捕获大多数高置信案例。
6. **成本可控**：总生成成本仅约$15，SEC是本地许可内计算，可并行化。
7. **核心失败模式被避免**：SEC无需刺激向量，在Claude测试台产生假共识（64b/66b编码器）和GPT测试台死锁（spec 122）的场景下仍正确工作。

## 8. 不足与局限

**基准与泛化性：**

- 实验局限于 **CVDP单一基准**（70个有效规格），未在其他RTL数据集（VerilogEval、RTLLM）验证，泛化结论有限。
- 所有规格源自同一benchmark，任务类型多样性受限（缺少大规模SoC级设计、时序约束类任务）。

**模型覆盖与偏差风险：**

- 仅4个LLM家族，且不涉及同一家族内多版本/多微调模型的比较——无法判断"同族共识"是否弱于"跨族共识"。
- 存在 **共享训练数据/公共语料偏差** 风险：不同模型家族可能在相同常见设计模式上表现出系统性相关错误，降低独立性假设的强度。
- LLM能力快速演进，模型选择可能使结果时效性受限。

**方法自身限制：**

- **覆盖率低**：四家族共识仅接受27%的规格，大量设计被延迟到常规流程——是安全的设计，但也意味着triage效率有限。
- **SEC不可判定性**：复杂设计的SEC可能返回inconclusive，此时无法产生等价边，降低覆盖；论文未报告每个规格的inconclusive具体分布。
- 依赖商业工具（JasperGold）与人工端口名推断（clk/reset/rst_n），自动化假设可能在某些设计风格下失效。
- 需要多个模型家族**同时可访问**；若组织只有单一授权模型，方法不可用。
- 提示模板固定、采样策略简单（每模型K=5），未探索温度、top-p等超参数对共识质量的影响。

**评估方法论：**

- ground truth本身依赖cocotb测试台——如果CVDP测试台存在遗漏漏洞场景，NoTB的高精度可能被高估；论文声称SEC证明的等价与测试台结果一致，但这只能在测试台覆盖范围内成立。
- 排除了编译失败/接口不匹配的候选，这类失败是"廉价信号"，统一应用于所有方法，但排除规则的主观性可影响结果可比性。
- 未与其他形式化方法（如模型检验、抽象解释）做对比，未与更强的agent式生成baseline对比。
