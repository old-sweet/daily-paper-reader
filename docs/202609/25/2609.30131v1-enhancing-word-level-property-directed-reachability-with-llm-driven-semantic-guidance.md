## 摘要
属性导向可达性（PDR）是硬件形式化验证中的一种重要算法。然而，位级PDR往往难以处理数据通路密集的设计，因为位爆破会掩盖高层语义。字级PDR通过对位向量和数组理论进行推理来应对这一问题，但其性能仍受限于发现与证明相关的字级关系。我们提出LLM4PDR，一个利用大语言模型（LLM）通过三种机制引导字级PDR搜索的框架：（1）谓词生成，在归纳泛化过程中提取状态关系作为候选谓词；（2）子句生成，在形式验证后生成候选帧引理以加速收敛；（3）断言生成，在反例引导的精化下合成增强目标属性的辅助断言。我们在Pono模型检测器中实现LLM4PDR，并在算术微基准、HLS生成的流水线、开源RTL组件以及硬件模型检测竞赛（HWMCC）实例上对其进行评估。结果表明，LLM生成的引导在数据通路密集以及控制加数据通路的设计上，既提升了求解实例数量，也改善了运行时间。最强配置求解了33个算术基准中的28个，而原始Pono求解13个，AVR求解11个。在HLS流水线和开源RTL上，不同模式提供了互补的加速：子句引导对深流水线有效，谓词引导对总线和存储器控制器设计有效。在HWMCC基准上，收益因实例而异，在困难案例上展现出显著加速并避免超时。这些结果表明，LLM生成且经验证器检查的语义提示可以作为传统字级PDR的实用补充。

## Abstract
Property Directed Reachability (PDR) is a prominent algorithm for hardware formal verification. However, bit-level PDR often struggles with datapath-heavy designs because bit-blasting obscures high-level semantics. While word-level PDR addresses this by reasoning over bit-vector and array theories, its performance remains bottlenecked by discovering proof-relevant word-level relations. We propose LLM4PDR, a framework leveraging Large Language Models (LLMs) to guide word-level PDR search through three mechanisms: (1) Predicate Generation, extracting state relationships as candidate predicates during inductive generalization; (2) Clause Generation, producing candidate frame lemmas to accelerate convergence after formal validation; and (3) Assertion Generation, synthesizing helper assertions that strengthen the target property under counterexample-guided refinement. We implement LLM4PDR in the Pono model checker and evaluate it on arithmetic micro-benchmarks, HLS-generated pipelines, open-source RTL components, and hardware model checking competition (HWMCC) instances. Results show LLM-generated guidance improves both solved instances and runtime on datapath-heavy and control-plus-datapath designs. The strongest configuration solves 28 of 33 arithmetic benchmarks, compared to 13 for vanilla Pono and 11 for AVR. On HLS pipelines and open-source RTL, different modes provide complementary speedups: clause guidance is effective for deep pipelines and predicate guidance for bus and memory-controller designs. On HWMCC benchmarks, benefits are instance-dependent, demonstrating notable speedups and timeout avoidance on hard cases. These results suggest that LLM-generated, verifier-checked semantic hints can serve as a practical complement to conventional word-level PDR.

## 2. 方法论

### 2.1 核心思想

- 提出 **LLM4PDR**：LLM 读取静态设计信息（RTL 或 BTOR2），生成受限 SMT-LIB2 辅助声明；验证器解析、类型检查、验证并精化这些声明。
- LLM 输出不被信任为证明，不修改转移系统或目标属性；可靠性边界始终保留在模型检测器内部。
- 在 PDR 工作流中识别三个自然注入点：
  - **谓词引导**：归纳泛化时扩展候选原子；
  - **子句引导**：主阻塞循环前向 F1 注入候选帧引理；
  - **断言引导**：属性检查时临时强化目标属性。

### 2.2 受限 SMT-LIB2 辅助接口

- 使用 `define-fun` 声明，保留前缀决定用途：
  - `predicate.*` → 辅助谓词池 `Pext`，供 MIC 使用；
  - `clause.*` → 辅助子句池 `Cext`，候选帧引理；
  - `assertion.*` → 辅助断言池 `Aext`，候选属性强化。
- 处理流程：语法解析 → 将形式参数绑定到状态变量并检查位宽 → 按前缀分派到对应验证路径。
- 同一个词级事实（如 `y = x + 2`）可分别作为谓词原子、F1 单元子句或强化属性使用。

### 2.3 COI 感知的提示构造与辅助合成

- 对目标属性做 **锥影响分析**，只保留可能影响属性的状态变量和转移片段。
- 在代表性 HWMCC 实例上，COI 过滤可移除 **52.35%–82.49%** 的状态变量，降低提示长度并减少无关候选。
- 固定提示模板包含：系统角色、few-shot 示例、COI 分析、任务描述、严格 SMT-LIB2 输出格式。
- 每个实例、每种模式最多请求 **5 个**辅助声明；三种设置仅验证器消费方式不同。

### 2.4 LLM 引导的谓词生成与两阶段 MIC

- 问题：普通 MIC 从 CTI 的位级 cube 出发，UNSAT core 可能只保留少量位文字，完全丢弃匹配到的词级谓词。
- **两阶段 MIC**：
  1. **第一阶段**：冻结匹配的辅助谓词 `Hp`，只允许移除位级文字 `B`，通过 UNSAT core 最小化得到 `B*`；
  2. **第二阶段**：逐个尝试删除辅助谓词，检查删除后 cube 是否仍不覆盖初始状态、是否仍相对当前帧归纳；若仍满足则删除冗余谓词。
- 最终子句需满足：
  - `I ⇒ g`（初始状态蕴含）；
  - `g ∧ F_{i-1} ∧ T ⇒ g'`（相对归纳）；
  - `g ⇒ ¬s`（排除证明义务）。
- 效果：保留必要词级结构，得到更紧凑的阻塞引理，而不是若干位切片文字。

### 2.5 LLM 引导的子句生成

- 辅助子句作为候选帧引理，通过 **side-loading** 注入 F1。
- 插入前执行两个健全性检查：
  - `UNSAT(Init ∧ ¬c)`：初始状态不得违反子句；
  - `UNSAT(Init ∧ T ∧ ¬c')`：初始状态的一步后继必须满足 primed 子句。
- 通过后 `F1 ← F1 ∧ c`，之后由普通 PDR 机制传播；若后续不相对归纳，则不会进入最终不变式。
- 适合表达完整帧引理，包括析取形词级关系，而不仅是单个谓词原子。

### 2.6 LLM 引导的断言生成

- 构造强化属性：`P* = P ∧ ⋀_{a∈V} a`，其中 `V ⊆ Aext` 是尚未被证伪的辅助断言。
- 因 `P* ⇒ P`，证明强化属性即可证明原属性。
- **反例引导精化**：
  - 若强化属性产生不可阻塞的坏 cube `c`，先在原属性 `P` 上评估；
  - 若 `P` 为假，则为真实反例，返回 UNSAFE；
  - 否则只删除被 `c` 证伪的辅助断言，重建 `P*` 并重启 PDR；
  - 最坏情况下所有辅助断言被删除，退化为普通 PDR。
- 辅助断言不加入转移关系，不被当作假设，仅作为暂定属性强化。
