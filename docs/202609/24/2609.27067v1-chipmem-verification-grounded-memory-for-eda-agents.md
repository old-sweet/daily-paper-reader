## 摘要
基于大语言模型（LLM）的智能体利用电子设计自动化（EDA）工具，在综合与验证反馈下生成和修改寄存器传输级（RTL）设计。近期方法通过学习这类反馈来提升能力：或从执行轨迹中蒸馏可复用技能，或基于由EDA工具推导的奖励进行训练。这两类方法通常都在产生经验的任务上进行评估。对同一任务重复访问基准反馈，可能奖励针对具体任务的修改，而非创造可迁移的可复用知识。我们提出ChipMEM，一种面向EDA智能体的验证锚定记忆层。它将跨任务程序性记忆与轨迹内统计指导相结合。其程序性组件仅在技能通过综合、仿真或形式化检查后才蒸馏并存储该技能，而不依赖模型自我评估。贝叶斯组件对工具调用结果维护分层Beta估计，并对在可比错误下成功的恢复策略进行排序。一个通用适配器将同一记忆接口应用于RTL优化和测试平台生成智能体，同时保留各领域的工具与验收标准。我们在训练任务上测量性能，并评估所学技能是否能迁移到未见任务。在RTLRewriter-Bench上，在匹配的模型和工具设置下，ChipMEM在39/54个计分设计上生成通过等价性检查的输出，而无记忆时为35/54；在49个设计的短套件上，平均面积改进为8.69%对5.66%。在留出的CVDP任务上，带有冻结程序库的ChipMEM在每种设置单次评估中取得20/20个可接受结果，而无记忆时为18/20。

## Abstract
Large language model (LLM)-based agents use Electronic Design Automation (EDA) tools to generate and revise register-transfer-level (RTL) designs under synthesis and verification feedback. Recent methods learn from this feedback by distilling reusable skills from execution traces or by training on rewards derived from EDA-tools. Both methods are typically evaluated on the tasks that produced the experience. Repeated access to benchmark feedback on the same task can reward task-specific revision rather than creating reusable knowledge that transfers. We introduce ChipMEM, a verification-grounded memory layer for EDA agents. It combines cross-task procedural memory with within-trajectory statistical guidance. Its procedural component distills and stores a skill only after it passes synthesis, simulation, or formal checks, rather than relying on model self-assessments. A Bayesian component maintains hierarchical Beta estimates over tool-call outcomes and ranks recovery strategies that succeeded under comparable errors. A common adapter applies the same memory interface to RTL optimization and testbench-generation agents while preserving each domain's tools and acceptance criteria. We measure performance on training tasks and evaluate whether learned skills transfer to unseen tasks. On RTLRewriter-Bench, under matched model and tool settings, ChipMEM produces equivalence-passing outputs on 39/54 scored designs versus 35/54 without memory; on the 49-design short suite, mean area improvement is 8.69% versus 5.66%. On held-out CVDP tasks, ChipMEM with a frozen procedural library achieves 20/20 accepted outcomes versus 18/20 without memory in a single evaluation per setting.

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的智能体已能借助 EDA 工具生成与修改 RTL 设计，并在综合、仿真、形式化验证反馈下迭代修正输出。
- **现有方法的两条路线**：
  - **参数化路线**：通过监督微调或强化学习直接修改模型权重。
  - **非参数化路线**：冻结模型，辅以精选技能库、搜索策略或工具在环反馈。
- **关键缺陷**：
  - 近期方法通常**在产生经验的任务上评估**，重复访问同一任务的基准反馈会奖励"任务特定修改"而非"可迁移知识"。
  - 存储的技能若来自不相似任务，不仅无效甚至可能**有害**（某设计的最优策略可能损害另一设计）。
  - 早期 RTL 决策（位宽、资源共享、状态编码）深刻影响 PPA，但这些经验常留在个别工程师手中，难以复用。
- **核心动机**：需要一个**由 EDA 工具认证内容**、并**通过跨任务迁移来衡量价值**的记忆层，而非仅在同一任务上评估。

## 2. 方法论

### 2.1 总体思想
ChipMEM 是一个**智能体无关（agent-agnostic）的记忆层**，将工具验证过的执行轨迹转化为两种互补记忆：
- **程序性记忆（Procedural Memory）**：跨任务保存可复用策略。
- **统计性记忆（Statistical Memory）**：在会话内/跨会话学习工具调用成功与恢复模式。

两者通过通用适配器接入智能体，不修改底层智能体、工具或验收标准。

### 2.2 程序性记忆
- **表示**：键值映射 \(M_{proc} = \{k_i \mapsto (v_i, m_i, h_i)\}\)，其中 \(v_i\) 为完整技能文件，\(m_i\) 为元数据（领域、任务、来源），\(h_i\) 为验证器结果。
- **键**：任务嵌入 \(k_i = \phi(z_i)\)，\(z_i\) 为任务工件（RTL 优化取顶层 RTL 文件；CVDP 取 `PROMPT.md`），**排除**智能体指令、检索技能、工具历史、生成文件等。
- **检索**：对当前任务嵌入 \(q_n\) 做余弦相似度检索，返回相似度超过阈值 \(\tau_{proc}\) 的 Top-K 技能。
- **存储门控**：**仅当执行通过领域确定性验证器（综合/仿真/形式化）得到 PASS 时才蒸馏并存储技能**，绝不用 LLM 自评作为门控。
- **两种模式**：
  - **演化模式（evolving）**：验证通过的技能可持续加入库中。
  - **冻结模式（frozen）**：库只读，用于评估迁移能力。

### 2.3 统计性记忆（贝叶斯分层模型）
- **两个二项分布模型**：重试预测器（retry predictor）+ 恢复预测器（recovery predictor）。
- **重试上下文**：\(x_t = (c_t, e_t, b_t)\)，其中 \(c_t\) 为工具调用类型，\(e_t\) 为上次错误类别（如 syntax-error、unknown-module、liberty-missing、timing-fail、rc-nonzero），\(b_t = \min(r_t, 3)\) 对重试次数饱和以抑制稀疏证据。
- **重试层次**：\(p_0 \to p_1(c_t) \to p_2(c_t, e_t) \to p_3(c_t, e_t, b_t)\)，递推为
  \[
  p_j = \frac{s_j + K \cdot p_{j-1}}{s_j + f_j + K}, \quad K=8
  \]
  最终估计 \(P_{retry}(\text{success} \mid c_t, e_t, b_t) = p_3\)。
- **恢复层次**：\(q_0 \to q_1(a) \to q_2(a, e_t) \to q_3(a, e_t, g_t)\)，同样用 Beta 递推（\(K=8\)），策略按 \(P_{recovery}\) 排序 \(\pi(e_t, g_t)\)。
- **触发机制**：当重复失败且 \(P_{retry} < \tau_{stat} = 0.20\) 时，激活恢复顾问，向 LLM 恢复规划器传入排序后的策略，返回有界建议计划。
- **原子持久化**：每次工具调用后立即更新证据，影响下一决策（包括同一会话内）。

### 2.4 智能体适配器与验证
- 适配器为智能体提供：原始任务 + 检索技能 \(R_n\) + 贝叶斯恢复建议；暴露领域工具、记录每次动作与结果、将最终工件交回验证器 \(V\)。
- **PPA 验收**：综合成功 + 功能等价 + 正的可审计改进。
- **CVDP 验收**：隐藏仿真、覆盖率与变异检查全部通过。
- **算法流程（Algorithm 1）**：初始化空程序库与 Beta(1,1) 先验 → 对每个任务嵌入并检索技能 → 智能体执行，每次工具调用后更新统计记忆，失败概率过低时触发恢复建议 → 结束后运行领域验证器 → 若 PASS 则蒸馏技能并入库，否则库不变。

## 6. 主要结论与发现

- **公开基准**：
  - RTL-OPT 平均面积改进从 6.18% 提升到 8.79%。
  - RTLRewriter-Bench 面积改进从 5.95% 提升到 8.88%；短套件等价性通过 35/54 → 39/54，平均面积 5.66% → 8.69%；单元/线网比从 5.9%/6.0% 降到 8.3%/8.0%。
- **完整 PPA**：
  - 自定义设计集面积/功耗改进 0.14%/0.39% → 0.31%/0.52%。
  - OpenTitan 面积/功耗 0.05%/0.00% → 0.24%/2.54%，时序稳定；严格门通过 1/10 → 4/10。
- **交互成本（OpenTitan）**：LLM 调用 29.4 → 26.1（−11.2%），工具调用 27.4 → 23.3（−15.0%），工具时间 420.2s → 369.8s（−12.0%），输入 token −6.8%，总 token −3.4%。
- **消融**：组合记忆在 5 个设计上达 5/5 严格通过、最高面积增益、最低每通过 token 消耗（Memory OFF 仅 3/5）。
- **冻结迁移（CVDP）**：CID013 从 8/10 → 10/10，整体 18/20 → 20/20；CID012 保持 10/10。因库只读，额外通过归因于迁移。
- **记忆学到了什么**：检索到的技能分为 Flow & Validation、Design Setup、RTL Optimization 三类，说明 ChipMEM

积累的是**可跨任务迁移的流程性知识**（如工具调用顺序、约束设置、验证前置检查），而非特定设计参数；其中 Flow & Validation 类技能占比最高，印证"验证前置"是主要收益来源。

- **统计记忆的作用**：在 OpenTitan 上，重试预测器与恢复顾问主要降低了重复失败带来的无效工具调用，体现为工具调用次数与工具时间下降，而非直接提升单次成功率。
- **总体判断**：ChipMEM 在"任务通过率"与"PPA 改进幅度"两个维度上均优于无记忆基线，且冻结迁移实验表明收益并非来自对评估任务的记忆泄漏，而是来自可迁移的策略与统计先验。

## 7. 局限与未来工作

- **验证器依赖性强**：程序性记忆的存储门控完全依赖领域确定性验证器；若某领域缺少可靠的自动化验证器（如早期架构探索、非形式化规格），ChipMEM 无法安全地蒸馏技能。
- **任务嵌入的敏感性**：检索质量取决于任务嵌入 \(k_i = \phi(z_i)\) 的语义区分度；对结构相近但优化目标相反的 RTL 任务，余弦相似度可能误召回有害技能，论文未深入分析此类负迁移案例。
- **统计记忆的稀疏性**：贝叶斯分层模型以 \(K=8\) 做收缩，虽缓解稀疏问题，但在工具调用样本极少的会话中，先验主导可能使 \(P_{retry}\) 估计偏差，进而误触发或漏触发恢复顾问。
- **实验覆盖不均**：如前所述，消融与冻结迁移样本量小，SWE-bench Pro 仅作试点，跨域泛化结论仍属初步；RTL-OPT/RTLRewriter 缺少功耗与时序的完整匹配流。
- **算力与成本报告不完整**：仅说明单张 A100，未报告总交互成本在更大规模任务上的可扩展性。
- **未来方向**（论文隐含或明确）：
  - 扩展到更多 EDA 子领域（布局布线、DFT、验证覆盖率收敛）。
  - 引入更细粒度的技能表示与冲突消解机制，避免不相似任务的负迁移。
  - 将统计记忆从二项分布扩展到带时间的生存模型或上下文 bandit，以更精细地刻画恢复策略的长期收益。
  - 建立跨组织的共享记忆库与隐私/知识产权保护机制。

## 8. 总体评价

- **核心贡献**：
  1. 提出**以工具验证为门控、以跨任务迁移为衡量标准**的记忆层范式，纠正了"在同任务上评估经验"的常见偏差。
  2. 设计**程序性记忆 + 统计性记忆**的双通道结构，分别对应"可复用策略"与"工具调用成功/恢复先验"，二者互补。
  3. 通过**冻结只读库的迁移实验**提供较严格的因果性证据，说明收益可迁移。
  4. 在公开基准与工业级流程上均报告一致的改进，并附带交互成本下降。
- **方法学亮点**：
  - 智能体无关、不修改底层模型与验收标准，具备良好的可插拔性。
  - 存储门控拒绝 LLM 自评，避免"自我强化错误"。
  - 贝叶斯分层收缩在稀疏证据下提供稳健估计。
- **主要不足**：
  - 关键消融与迁移实验样本量偏小，统计功效有限，部分配对置信区间跨越零。
  - 部分结果（OpenTitan）来自与当前学习规则不一致的旧版运行，仅作描述性参考。
  - 缺少对负迁移与失败案例的系统分析。
  - 资源报告不完整，缺少训练/推理总成本的完整核算。
- **适用性判断**：ChipMEM 最适合**拥有确定性验证器、任务可大量重复且需跨任务复用经验**的 EDA 场景（如 RTL 优化、测试平台生成）；在验证器缺失或任务高度异构的场景中，其收益与安全性尚待验证。
- **结论**：作为一篇聚焦"经验如何被安全存储与跨任务复用"的工作，ChipMEM 提供了清晰的问题定义、可复现的方法框架与初步但一致的实证支持；若后续能在更大样本、更完整 PPA 流与负迁移分析上补强，将更具说服力。
