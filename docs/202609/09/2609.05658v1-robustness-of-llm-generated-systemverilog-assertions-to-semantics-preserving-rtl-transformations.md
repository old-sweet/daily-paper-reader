## 摘要
大型语言模型（LLM）越来越多地被探索用于自动化SystemVerilog断言（SVA）生成，然而大多数评估仅报告对输入单一语法表示的正确性。这种点准确度并不能揭示当相同RTL行为以不同方式编写时，模型的正确输出是否稳定。本文对基于LLM的SVA生成在保持语义的RTL变换下进行了受控变形评估。从VERT数据集出发，我们构建了一个质量过滤的条件控制池和一个分层的40程序评估集，包含295个赋值行为。我们使用相同的评估提示和贪婪解码评估了两个开放代码模型：Qwen2.5-Coder-7B和DeepSeek-Coder-V2-Lite。研究了三种变换：操作数重排序、确定性标识符重命名和冗余括号化。除了基线和变换后的准确度外，我们在RTL程序级别上通过10,000次采样的聚类自举区间测量了条件鲁棒性、不变性失败和任意翻转率。在所有六种模型-变换条件下，原始RTL上正确的行为中有9.7%-27.0%在经保持语义的变换后变得不正确。因此，总体准确度可能掩盖显著的不稳定性：在标识符重命名下，DeepSeek-Coder-V2-Lite的准确度从53.9%提高到63.7%，而其原始正确的行为中有19.5%失败。对30个正确到错误转变的抽样人工审查识别出丢失路径谓词、分支极性错误、布尔结构损坏和输出契约违反。结果表明，仅凭点准确度不足以表征LLM在断言生成中的可靠性，并促使对AI辅助硬件验证进行鲁棒性感知的评估。

## Abstract
Large language models (LLMs) are increasingly being explored for automating SystemVerilog Assertion (SVA) generation, yet most evaluations report correctness on a single syntactic representation of an input. Such point accuracy does not reveal whether a model's correct output is stable when the same RTL behavior is written differently. This paper presents a controlled metamorphic evaluation of LLM-based SVA generation under semantics-preserving RTL transformations. Starting from the VERT dataset, we construct a quality-filtered conditional-control pool and a stratified 40-program evaluation set containing 295 assignment behaviors. We evaluate two open code models, Qwen2.5-Coder-7B and DeepSeek-Coder-V2-Lite, with an identical evaluation prompt and greedy decoding. Three transformations are studied: operand reordering, deterministic identifier renaming, and redundant parenthesization. Beyond baseline and transformed accuracy, we measure conditional robustness, invariance failure, and any-flip rate, with 10,000-sample clustered bootstrap intervals at the RTL-program level. Across all six model-transformation conditions, 9.7%-27.0% of behaviors that were correct on the original RTL become incorrect after a semantics-preserving transformation. Aggregate accuracy can therefore hide substantial instability: under identifier renaming, DeepSeek-Coder-V2-Lite improves from 53.9% to 63.7% accuracy while 19.5% of its originally correct behaviors fail. Manual review of 30 sampled correct-to-wrong transitions identifies dropped path predicates, branch-polarity errors, Boolean-structure corruption, and output-contract violations. The results show that point accuracy alone is insufficient for characterizing LLM reliability in assertion generation and motivate robustness-aware evaluation for AI-assisted hardware verification.

### 1. 论文的核心问题与整体含义

- **研究动机**：LLM 越来越多地被用于自动化生成 SystemVerilog Assertion（SVA），但绝大多数评测仅报告模型在 RTL 的**单一语法表示**上的“点正确率”（point correctness）。这种评测无法回答一个实践中的重要问题：当同一 RTL 行为以不同但语义等价的写法呈现时，模型原本正确的输出是否依然稳定。
- **核心研究问题**：LLM 生成的 SVA 正确性是否对“保持语义的 RTL 表示变化”（semantics-preserving RTL transformations）保持鲁棒？
- **整体含义**：硬件验证流程中 RTL 常被重构、格式化、重命名或规范化，如果 LLM 只能针对某一种表面形式生成正确断言，则基准测试上的高准确率会掩盖部署中的脆弱性。论文主张：**点准确率不足以保证 LLM 在断言生成上的可靠性**，评测应引入鲁棒性感知的维度。

### 2. 方法论

- **核心思路**：采用 **蜕变测试（metamorphic testing）** 的框架，在语义保持的 RTL 变换前后分别让模型生成 SVA，并检查正确性是否保持。核心关系为：若 RTL 输入语义不变，则生成的断言也应当保持语义正确。
- **数据构建流程**：
  - 从 VERT 数据集（20,000 条 RTL/SVA 记录）出发；
  - 筛选出 10,400 条条件控制（nested-if 与 if/else-tree）候选；
  - 通过质量过滤（剔除重复属性名和异常属性计数记录）保留 **9,157 条合格记录**；
  - 进一步构造 **40 个受控 RTL 程序**的分层抽样集，按同步/异步与结构类型四层均衡抽样；
  - 40 个程序的参考断言分解为 **295 个赋值行为（assignment behaviors）**。
- **三种语义保持变换**：
  - **T1：操作数重排序**：对同质、可交换的顶层逻辑与/或表达式反转操作数顺序；
  - **T2：确定性标识符重命名**：将标识符一致地重命名为中性名称（如 `id_000`），评分前进行逆映射，以隔离标识符表面形式的影响；
  - **T3：冗余括号化**：在条件与操作数周围添加语法冗余的括号，不改变非括号 token 顺序或运算符顺序。
- **评测模型与设置**：
  - Qwen2.5-Coder-7B-Instruct-4bit；
  - DeepSeek-Coder-V2-Lite-Instruct-4bit；
  - 两模型使用**完全相同的评测提示（prompt）**和**贪婪解码（greedy decoding，temperature=0）**，最大生成 token 数为 1,536。
- **行为级语义评分器**：
  - 逐赋值行为独立评分；生成属性需满足输出契约（property/timing 格式、每行为一条 property、consequent 匹配赋值行为），并且其前件在受限布尔语法下与参考路径条件命题等价。
  - 采用≤16个布尔原子的全真值表穷举比价，并对相等/不等比较形式做规范化。
- **关键指标**：
  - 基线/变换后准确率：\(A_B = B/N\)、\(A_T = T/N\)；
  - 准确率变化：\(\Delta A = A_T - A_B\)；
  - 条件鲁棒性：\(CR = R/B\)；
  - **不变性失败：\(IF = L/B = 1 - CR\)**（原本正确但变换后错误的比率，为最主要指标）；
  - 任意翻转率：\(Flip = (L+G)/N\)。
- **统计方法**：以 RTL 程序为聚类单位进行 **10,000 次非参数聚类 bootstrap**，报告 95% 百分位置信区间；不使用行为作为独立样本。

### 6. 主要结论与发现

- **RQ1（总体准确率）**：
  - Qwen2.5-Coder-7B 基线约 70%；T1/T2 变化不大，但 T3 下准确率从 69.8% 降至 58.6%（−11.2 个百分点，95% CI [−21.3, −2.2]，是唯一置信区间不跨零的聚合变化）。
  - DeepSeek-Coder-V2-Lite 基线约 53.2–53.9%；T1 提升 5.0 点、T2 提升 9.8 点、T3 下降 4.1 点。
  - 因此“语义保持变换一定降低聚合准确率”的简单假设不成立。
- **RQ2（不变性失败）**：
  - 所有六个模型–变换组合均出现“原本正确→变换后错误”的不变性失败；
  - IF 范围为 **9.7%–27.0%**；
  - T3 对两个模型破坏性最大：Qwen IF = 21.8%，DeepSeek IF = 27.0%；

  - 任意翻转率最高达 30.8%（DeepSeek T2）。
- **RQ3（人工错误分析）**：
  - 30 个抽样“正确→错误”转变均为真实失败，无明显评分子伪阳性；
  - 主要失败模式包括：**丢失路径谓词**、**分支极性错误**、**布尔结构损坏**与**输出契约违反**（如多行为合并到一个 consequent）；
  - 失败不仅发生在生僻语法上：单纯的操作数重排或加括号也可能导致前件条件丢失或控制流谓词组合错误。
- **总体判定**：聚合准确率无法反映表示敏感性问题；在 RTL 被以语义等价的另一种写法呈现时，LLM 断言生成正确性会实质性变化。

### 7. 优点

- **问题设计具有现实意义**：将蜕变测试从软件代码模型引入 SVA/硬件验证场景，切入点清晰、实用动机充分。
- **变换选择干净可控**：三种变换均语义保持且易于解释；T1 限制在同质可交换运算组，T2 使用一致 alpha 重命名并逆映射评分，T3 不改变 token 序列顺序，便于归因鲁棒性失败。
- **指标设计突出**：区分聚合准确率（accuracy）与稳定性（CR/IF/Flip），使“总准确率上升但旧正确行为退化”这一非直观现象成为可量化指标。
- **统计方法合适**：使用 RTL 程序级聚类 bootstrap，不把同一程序内数百个行为当作独立样本，在不确定性估计上显著优于按行为简单平均。
- **评测过程标准化**：两模型同一 prompt、同一解码、同一评分标准，减小评估偏差；行为级语义评分器补充了语法正确性之外的真值表等价检查。
- **人工审查验证**：对失败样本进行人工审计，排除了主要评分伪影，增加结果可信度；对数据集过滤范围也做了诚实说明。

### 8. 不足与局限

- **样本规模限制**：仅 40 个受控 RTL 程序、295 个赋值行为；论文自己强调这是受控研究而非总体估计，不能对 VERT 全量或更大 RTL 范围做统计外推。
- **数据集/范围限制**：
  - 只研究了条件控制结构（nested-if 与 if/else-tree），排除 case 语句、时序复杂结构、算术密集型 RTL、协议级属性等；
  - VERT 本身含合成增强数据，与手写产品级 RTL 有差异。
- **语义抽象局限**：
  - 评分器仅覆盖受限布尔语法与逻辑等价检查，不模拟 SystemVerilog 四态 X/Z 语义，不支持任意位向量算术和广义时序 SVA 构造；
  - 不是对最终断言的完整形式验证或仿真验证。
- **模型覆盖不足**：
  - 仅两个开源模型，且都在同一台 Apple M1 上用 4-bit MLX 量化本地推理；量化可能引入输出分布偏差，不能由此推广至模型家族/规模/量化策略。
- **变换有效性风险**：
  - 变换“保持语义”依赖实现正确性，论文承认可能有实现 bug，因此强调发布变换脚本和输入以供复现。
- **无因果解释**：
  - 实验仅显示表示敏感性存在，不能解释其机制——不确定是分词、训练分布、代码风格先验、prompt 交互、量化或模型能力问题所致，作者也明确不进行因果归因。
- **统计功效偏低**：
  - 40 个聚类下置信区间宽，除 Qwen T3 的 ΔA 和全部 IF 区间外，多数聚合差异在统计上不显著；论文未提供正式的假设检验框架，更多是描述性证据。
- **未探索缓解方案**：论文建议可将输出不一致作为置信度信号或引入多次变体一致性检查，但并未实际验证该干预的有效性，后续工作空间较大。
